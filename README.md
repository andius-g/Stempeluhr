# Stempeluhr

Persönliche Progressive Web App (PWA) zur lokalen Arbeitszeiterfassung auf dem Smartphone und Desktop.

## Funktionen
- **Design-Pakete:** Wählbare Oberflächen (*Cremig & One-Line-Art*, *Glassmorphism*, *Neumorphism*, *Nacht / OLED*)
- **Layouts:** Umschaltbar zwischen *Kompakt* und *Detail*
- **Navigation:** Deckende Ansichten (*Heute*, *Woche*, *Menü*) mit horizontalem Wischen ohne Durchblitzen
- **Wochenkalender:** Schnelles Blättern durch die Kalenderwochen inklusive *Heute*-Sprung
- **Scribbles:** Eigener Bereich im Menü für Freihand-Notizen und Skizzen
- **3-Punkt-Farbrad:** Drei unabhängige Punkte für Grund-, Karten- und Akzentfarbe
